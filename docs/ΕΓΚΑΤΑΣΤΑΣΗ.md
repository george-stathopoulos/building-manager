# Εγκατάσταση

## 1. Δημόσια εφαρμογή

Το GitHub Actions πραγματοποιεί έλεγχο και κατασκευή της εφαρμογής. Στις ρυθμίσεις του αποθετηρίου επιλέγουμε **Pages → Build and deployment → GitHub Actions**. Η εφαρμογή δημοσιεύεται στη διεύθυνση:

https://george-stathopoulos.github.io/building-manager/

Πριν συνδεθεί η υπηρεσία δεδομένων, η εφαρμογή εμφανίζεται **μόνο για επίδειξη** και δεν αποθηκεύει πραγματικές οικονομικές πληροφορίες.

## 2. Ιδιωτική βάση δεδομένων Cloudflare D1

Από τον φάκελο `api`:

```bash
npm install
npx wrangler login
npx wrangler d1 create building-manager-db
```

Αντιγράψτε το αναγνωριστικό που επιστρέφεται στο `api/wrangler.toml` ως `database_id`.

Εφαρμογή αρχικού σχήματος:

```bash
npx wrangler d1 migrations apply building-manager-db --remote
```

**Προσοχή:** Η αρχική βάση περιέχει μόνο τους κωδικούς διαμερισμάτων και συντελεστές θέρμανσης. Δεν περιέχει οικονομικές συναλλαγές.

## 3. Κλειδί πρώτης εγκατάστασης

Δημιουργήστε τυχαίο μυστικό τουλάχιστον 24 χαρακτήρων. Προσθέστε το ως μυστική μεταβλητή χωρίς να το καταχωρίσετε ποτέ στο GitHub:

```bash
npx wrangler secret put ADMIN_SETUP_KEY
npx wrangler deploy
```

Ο πρώτος διαχειριστής δημιουργείται από την οθόνη «Αρχική εγκατάσταση». Μετά τη δημιουργία πρώτου χρήστη, αυτή η λειτουργία απενεργοποιείται.

## 4. Σύνδεση GitHub Pages με Workers

Στις ρυθμίσεις του αποθετηρίου δημιουργήστε μεταβλητή **Actions variable** με όνομα `VITE_API_URL` και τιμή τη δημόσια διεύθυνση του Worker (χωρίς τελικό /).

Εκκινήστε ξανά τη ροή «Δημοσίευση εφαρμογής».

Η διεύθυνση `WEB_ORIGIN` του Worker πρέπει να είναι ακριβώς `https://george-stathopoulos.github.io`.

## 5. Ασφάλεια και δεδομένα

- Μη δημοσιεύετε το κλειδί εγκατάστασης, κωδικούς, προσωπικά στοιχεία ή αντίγραφα της βάσης στο αποθετήριο.
- Η πρώτη έκδοση αποθηκεύει προσωρινό διακριτικό σύνδεσης στον χώρο της συνεδρίας του προγράμματος περιήγησης και χρησιμοποιεί κανόνες πρόσβασης ανά ρόλο στον εξυπηρετητή.
- Πριν χρησιμοποιηθεί με πραγματικές πληρωμές, απαιτούνται έλεγχος ασφαλείας, δοκιμές ταυτόχρονης χρήσης, διαδικασίες αντιγράφων ασφαλείας και επικύρωση των συντελεστών κατανομής.
- Δεν έχουν ενεργοποιηθεί αυτόματες χρεώσεις θέρμανσης. Προηγείται επαλήθευση με το ιστορικό Google Sheets.
- Η αποθήκευση ιδιωτικών παραστατικών δεν περιλαμβάνεται ακόμη. Δεν πρέπει να ανεβαίνουν τιμολόγια στο δημόσιο αποθετήριο.
