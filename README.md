# Διαχείριση Πολυκατοικίας

Ελληνόφωνη εφαρμογή διαχείρισης κοινοχρήστων και θέρμανσης. Η εφαρμογή θα φιλοξενείται δωρεάν μέσω GitHub Pages, ενώ τα ιδιωτικά στοιχεία διατηρούνται εκτός του δημόσιου αποθετηρίου.

## Ανάπτυξη

```bash
npm install
npm run dev
```

Τα πραγματικά στοιχεία κατοίκων, πληρωμών και διαμερισμάτων **δεν** δημοσιεύονται στο GitHub.
