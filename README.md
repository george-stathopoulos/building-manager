# Διαχείριση Πολυκατοικίας

Ελληνόφωνη εγκαταστάσιμη διαδικτυακή εφαρμογή για κοινόχρηστα, θέρμανση, καταθέσεις και ιστορικό έξι διαμερισμάτων.

## Αρχιτεκτονική

- GitHub Pages: δημόσια αρχεία εφαρμογής (χωρίς ιδιωτικά δεδομένα).
- Cloudflare Workers: εξουσιοδοτημένο περιβάλλον εξυπηρέτησης αιτημάτων.
- Cloudflare D1: οικονομικά δεδομένα, μετρήσεις και λογαριασμοί κατοίκων.
- Χωρίς υποχρεωτική υπηρεσία επί πληρωμή. Τηρούνται τα όρια των δωρεάν προγραμμάτων.

## Τοπική εκκίνηση

1. Εκτέλεση `npm install`.
2. Εκτέλεση `npm run dev`.
3. Για σύνδεση με το σύστημα δεδομένων, δημιουργήστε αρχείο `.env.local` με `VITE_API_URL=https://...workers.dev`.

Χωρίς τη ρύθμιση εξυπηρέτησης εμφανίζεται **λειτουργία επίδειξης**, χωρίς πραγματικά οικονομικά στοιχεία και χωρίς αποθήκευση.

## Έλεγχοι

`npm run build` · `npm run test`

## Ασφάλεια

Δεν αποθηκεύουμε πραγματικές πληρωμές, προσωπικά δεδομένα ή διαπιστευτήρια στο δημόσιο GitHub. Οι κάτοικοι βλέπουν μόνο τα δεδομένα των διαμερισμάτων στα οποία διαθέτουν πρόσβαση. Δεν χρησιμοποιείται το ιστορικό Google Sheets για δημόσια δεδομένα επίδειξης.

Ο αρχικός υπολογισμός κατανομής κοινοχρήστων υποστηρίζει ισομερή κατανομή και βάρη. **Οι χρεώσεις θέρμανσης δεν οριστικοποιούνται πριν ελεγχθεί ο τύπος υπολογισμού της πολυκατοικίας.**

Δείτε `docs/ΕΓΚΑΤΑΣΤΑΣΗ.md` και `docs/ΛΟΓΙΣΤΙΚΗ.md`.
